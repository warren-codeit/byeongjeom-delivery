# 부대찌개 배달 대작전!!

부대찌개집 아들이 만든 배달 레이싱 게임. 배달 라이더가 되어 병점역에서 주공 11단지까지 부대찌개를 120초 안에, 국물 안 쏟고, AI 라이더 4명보다 먼저 배달한다. 실제 병점 도로망 위를 마음대로 달리고 길 안내판·도로 위 화살표·미니맵이 길을 알려 준다. 드리프트로 부스터를 모으고, ? 박스에서 아이템을 얻어 쓰고, 점프해서 육수 팩을 먹고, 정면에서 달려드는 국물 도둑을 피한다.

## 왜 만들었나

부모님이 화성 병점에서 땅스부대찌개 가맹점을 하신다. 밀키트 포장·배달이 주력이라 「배달 가는 동안 국물이 안 넘치게」가 집에서 늘 듣던 이야기였다. 그 길을 게임으로 옮겼다. 출발점은 병점역, 도착점은 우리 집이 있는 주공 11단지, 도로는 OpenStreetMap에서 내려받은 실제 병점 도로망이다. 게임 안 지명(병점사거리·병점지하차도교차로·중심상가·롯데시네마 정류장)도 전부 실제 위치에 있다.

이 게임은 개인 프로젝트이고 땅스부대찌개 본사와 무관하다. 제목의 「feat. 땅스부대찌개 병점점」은 부모님 가게를 가리키는 표기일 뿐이며, 브랜드 로고·캐릭터는 쓰지 않았다. 시작·결과 화면의 부대찌개 사진과 메뉴판(`assets/img/`)은 병점점이 네이버 플레이스에 올린 사진이다. 주문표의 메뉴 이름(가득햄·깡통햄·모둠·십센치·토마토·베이컨·왕만두·치즈 부대찌개)도 그 메뉴판에서 가져왔다.

## 어떻게 노나

- 출발 전에 주문표(보통맛·매운맛, 추가 사리 2종)를 보고 맞는 냄비를 고른다. 틀리면 점수가 반이 된다.
- 카운트다운 뒤 GO 직후에 ↑를 누르면 출발 부스터가 터진다.
- AI 라이더 4명과 같은 경로를 달린다. 왼쪽에 순위표, 오른쪽에 내 순위가 뜨고, 도착 순위에 따라 보너스가 붙는다(1위 +300, 앞지른 한 명당 +150). 부딪히면 서로 밀리기만 하고 국물은 안 샌다.
- 길은 정해져 있지 않다. 실제 도로망 어디로든 갈 수 있고, 왼쪽 위 길 안내판(「우회전 120m」)·도로 위를 흐르는 노란 화살표·코너의 회전 표지·미니맵이 추천 경로를 알려 준다. 경로에서 멀어지면 화살표가 빨개지고 안내판이 「경로 이탈」로 바뀐다. 막다른 곳에 끼이면 R 키로 경로에 복귀한다(국물 −8).
- ? 박스를 먹으면 룰렛이 돌고 아이템 하나가 들어온다(E 키·아이템 버튼). 냄비 뚜껑은 다음 충돌 1회를 막고, 니트로는 즉시 부스터, 고추장 폭탄은 앞으로 날아가 도둑·차·라이더를 날리고, 사리 자석은 6초간 사리와 육수 팩을 끌어오고, 물풍선은 앞에 떨어져 주변 도둑·차·라이더를 3초 세운다. 물체마다 이름표가 떠서 무엇인지 보인다.
- 인도·잔디로 올라가면 덜컹거리며 속도가 떨어지고 국물이 샌다. 건물에 부딪히면 튕겨 나온다. 요철·주차 차량·보행자·마주 오는 차를 피하고, 빨간불에서는 멈춘다.
- 시속 86km(24m/s)를 넘기면 국물이 샌다. 국물이 0이 되면 실패, 120초가 지나면 찌개가 식어 실패.
- 공중에 떠 있는 육수 팩을 점프해서 먹으면 국물이 25 찬다. 땅에서 스치면 안 먹힌다.
- 국물 도둑(빨간 느낌표를 단 카트)이 앞에서 나타나 정면으로 달려들고, 지나치면 잠깐 뒤쫓는다. 닿으면 국물을 크게 빼앗기고, 가까이서 경적을 울리면 움찔해 물러난다. 8m 안에서는 직진만 하므로 마지막 순간에 비키면 된다.
- 길에 떨어진 사리를 주우면 점수가 오르지만 냄비가 무거워져 출렁임이 커진다. 주문표의 사리를 주우면 보너스.
- 가속은 직접 해야 한다. 손을 떼면 서서히 느려지고, 브레이크를 계속 밟으면 후진한다. 속도가 빠를수록 핸들이 덜 꺾인다.
- 드리프트: 방향키를 누른 채 Shift. 차체가 기울고 뒷바퀴가 크게 미끄러지며 스키드 자국·불꽃(파랑→주황→금색)이 남고 부스터 게이지가 찬다. 드리프트 중 반대 방향키로 반경을 조절한다. 놓는 순간 순간 부스터가 붙고, 게이지가 차 있으면 풀 부스터가 터져 시속 144km까지 붙는다. 부스터와 그 직후 1초는 국물이 새지 않는다. 드리프트 중에는 국물이 조금씩 샌다.
- 점프로 요철을 넘을 수 있다. 착지 때 국물이 조금 출렁인다. 화면을 두 번 두드리면 경적이 울리고 횡단보도 보행자가 뛰어서 비키며, 길가의 비둘기 떼는 카트가 다가가면 날아오른다.
- 부딪히면 국물이 튀고 화면이 흔들리며 잠깐 느려진다. 차와 부딪히면 부품이 튀고 부스터가 꺼진다. 콘은 날아간다. 진동을 지원하는 폰은 진동한다.
- 조작: 키보드 ↑ 가속 · ↓ 브레이크·후진 · ← → 조향 · 스페이스 점프 · Shift 드리프트 · E 아이템 · H 경적 · R 경로 복귀. 폰은 하단 버튼 7개(좌회전·우회전·브레이크·드리프트·점프·아이템·가속 꾹).

점수 = 국물 잔량 × 10 + 남은 초 × 20 + 주문 사리 300 + 그 외 사리 80 + 부스터 1회 50 + 순위 보너스. 결과 화면의 공유로 점수가 담긴 링크와 결과 카드를 보낼 수 있다.

## 실제 지도를 쓴 방법

- 건물은 OSM 발자국마다 Kenney City Kit 건물 모델을 발자국의 가장 긴 변 방향으로 돌려 크기에 맞게 늘려 세웠다(아파트는 고층 모델 26~48m, 나머지는 5~16m). 모델 19종을 InstancedMesh로 그려 건물 1,100개가 드로우콜 약 20번이다. 가로수·가로등·쓰레기통·옆길 주차 차량은 경로와 도로를 따라 건물을 피해 놓았다.
- 도로·건물·철도·횡단보도·신호등: OpenStreetMap에서 병점역 일대 약 2km×2km를 Overpass API로 한 번 내려받아 [`tools/build-map.py`](tools/build-map.py)로 미터 좌표계 JSON([`assets/data/map.json`](assets/data/map.json), 190KB)으로 구웠다. 게임은 이 파일만 읽고 화면은 캔버스로 직접 그린다. 외부 지도 타일이나 API 키가 없다.
- 경로: 병점역 → 주공 10·11단지 정류장, OSRM 공개 서버의 자동차 경로(1,757m). 게임 안에서 2m 간격으로 다시 샘플링해 1,787m.
- OSM의 이름 있는 지점(가게·은행·병원·카페·정류장 224곳)도 같이 구웠다. 경로 옆 건물의 간판은 건물 이름이나 가장 가까운 실제 가게 이름(롯데시네마·스타벅스·파리바게뜨·병점우체국 등)을 쓰고, 버스 정류장은 실제 정류장 위치에 실제 이름으로 세웠다. 이름이 없는 건물만 가공의 상호를 붙였다.
- 병점역은 경부선 선로 위에 승강장 2면(스크린도어·캐노피·벤치), 선상 역사, 계단을 세우고 승객 16명이 오간다. 열차 2편성이 양방향으로 달리다 역에 7초 정차한다.
- 횡단보도와 신호등은 지도에 실제로 있는 위치를 경로에 투영해 배치했다. 요철·주차 차량·사리·육수 팩·아이템 박스는 판마다 무작위.
- 주행 가능 판정은 도로 중심선과 도로 등급별 폭(간선 15m, 보조 11m, 주택가 7.5m, 골목 4.5m)으로 하고, 건물은 OSM 발자국 다각형 그대로 충돌 판정한다. 도로 포장 위로 들어온 작은 구조물(정류장 등)은 뺐다.

## 참고한 바이럴과 무엇을 다르게 했나

Vibe Jam 2026 1위 「카피바라 음식 배달」에서 「배달 게임이 통한다」는 것만 가져왔다. 이 게임의 핵심 규칙인 국물 게이지(속도·무게·요철에 따라 샌다)는 밀키트 배달에서 나온 것이고, 무대는 가공의 마을이 아니라 실제 병점 도로다.

## 스택·제작

- 단일 `index.html` + three.js r160(로컬 사본, GLTFLoader·SkeletonUtils 포함). 빌드 없음, 서버 없음. 고해상도 폰은 내부 해상도를 낮춰 그린다.
- 3D 모델은 [Kenney](https://kenney.nl)의 CC0 키트(Car Kit·City Kit Roads·City Kit Commercial·Nature Kit·Mini Characters)에서 50개를 골라 [`assets/models/`](assets/models/)에 넣었다. 주차 차량·건물·나무·가로등·전신주·도로 표지·신호등·행인(걷기 애니메이션)·콘·쓰레기통·충돌 파편이 여기서 나온다. 배달 오토바이와 라이더, 냄비·사리·아이템·간판·정류장·병점역·열차·생울타리·벤치·파티클은 코드로 그렸다. 출처 표기 의무는 없지만 푸터에 적었다.
- 소리는 Web Audio로 합성. 서체는 [땅스부대찌개체](https://tsbudae.com/brand/?c=72)(개인·기업 무료, 웹 임베딩 허용, [라이선스](assets/fonts/LICENSE-땅스부대찌개체.pdf)).
- 제작: 2026-09-15, Claude Code. 2D 캔버스 1차 약 15분 → three.js 3D 전환·이펙트 약 25분 → Kenney 모델 도입·드리프트·부스터·조작 개편 약 40분 → 차선 고정을 버리고 자유 주행으로 전환(조향 물리·노면 판정·경로 안내·미니맵), 드리프트 재설계, 육수 팩·국물 도둑·마주 오는 차·비둘기 추가, 경로 판정 버그 수정 약 90분 → 오토바이·AI 라이더 4명·아이템 5종·길 안내판·이름표·병점역·열차·실제 상호 간판·지형지물 밀도 약 70분. 기획 논의 시간 제외. 이전 네 버전은 저장소 밖에 보관.
- 배포: Vercel 정적 서빙([`vercel.json`](vercel.json)).

## 개발

```bash
python3 -m http.server 8000            # 로컬 실행 (fetch 때문에 file:// 로는 안 열린다)
node tools/headless-run.mjs 'http://127.0.0.1:8000/?auto=1&speed=8' 150 out.png state
```

두 번째 명령은 헤드리스 크롬으로 자동 주행을 8배속으로 돌려 결과 상태와 스크린샷을 남긴다. 난이도는 `index.html` 맨 위 `CFG` 숫자로 조정한다. `?auto=1`은 자동 주행, `?speed=N`은 배속, `&trace=1`을 더하면 `window.TRACE`에 1초마다 위치·속도·노면이 쌓인다. 세 가지 다 검증용이다. 물리는 프레임과 무관하게 0.02초 이하로 나눠 돌리므로 배속을 올려도 판정이 거칠어지지 않는다.

## 알려진 한계

- 지도는 2026-05 OSM 스냅숏이다. 도로가 바뀌면 `tools/build-map.py`를 다시 돌린다.
- 건물 모델을 발자국 크기에 맞춰 비균등하게 늘려서, 길쭉한 건물은 창문 비율이 어긋난다. 발자국 모양이 L자면 직사각형으로 뭉뚱그려진다.
- 자동 주행은 순수 추적 조향이라 주차 차량·국물 도둑을 사람보다 자주 들이받는다(라이더 경쟁판 3회 중 1회 완주·1위). 밸런스는 실기기 기준으로 본다.
- 오토바이·라이더·역·열차는 기본 도형으로 조립한 것이라 가까이서 보면 단순하다.
- OSM의 효행로는 방향별로 도로선이 따로 있어 추천 경로가 한쪽 차도의 중심을 지난다. 두 차도를 한 덩어리로 그리므로 경로가 도로 한쪽에 치우쳐 보이는 구간이 있다.
- 결과 카드 이미지 공유는 Web Share API를 지원하는 모바일 브라우저에서만 되고, 데스크톱은 링크 복사로 대신한다.
